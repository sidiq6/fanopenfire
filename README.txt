OPENFIRE - HTML CSS JAVASCRIPT SAJA

CARA MEMBUKA:
Klik dua kali index.html untuk melihat website di browser.

CARA HOSTING TANPA GITHUB:
1. Buka https://vercel.com/drop
2. Upload folder ini atau ZIP OPENFIRE_STATIC_HTML_CSS_JS.zip.
3. Ikuti proses deploy.

STRUKTUR:
index.html - halaman utama
assets/css/style.css - desain
assets/js/main.js & extras.js - interaksi
assets/images/ - 49 gambar asli dalam format teroptimasi
vercel.json - konfigurasi opsional Vercel

Tidak memakai PHP, MySQL, Node.js, ataupun dashboard admin.
Harga menu tidak ditampilkan karena belum diberikan.
